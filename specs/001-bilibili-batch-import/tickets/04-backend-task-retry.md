# 04 · 后端：任务级自动重试

- **依赖**：03
- **关联**：spec §7

## 目标

整条笔记任务（下载 / 转写 / LLM）失败后自动重试，最多 3 次，指数退避。

## 改动点

1. 在 `NoteGenerator.generate` 外层或任务入队处包一层重试包装。
2. 退避：5s / 15s / 45s（可配置）。
3. 重试期间更新任务 status.json 的 message（如 `重试中 (2/3)`），保持前端可见。
4. 达上限后写 FAILED，批量端点据此返回 `failed`。

## 验收

- 构造「前 N 次失败、第 N+1 次成功」的桩，断言重试次数与最终 SUCCESS；
- 始终失败时最终为 FAILED 且不影响其他 task；
- 重试次数语义按 spec 待确认 #4 定。
