# 06 · 前端：展开弹窗与勾选

- **依赖**：02
- **关联**：spec §8

## 目标

粘贴合集/多P URL 后可弹出大列表，勾选要生成的分P。

## 改动点

1. `BillNote_frontend/src/services/note.ts` 新增 `expandUrl(url)`。
2. 新增 `BatchImportDialog` 组件：
   - 大显示区表格：勾选 / 标题 / 时长 / 分P / 已生成（置灰）；
   - 全选、全不选按钮；
   - `x-x` 范围输入框，前端解析为勾选集（spec 待确认 #3）；
   - 多P 视频可折叠/展开其分P。
3. `NoteForm` 增加「批量导入」入口；或提交时识别合集 URL 自动打开弹窗。
4. `/expand` 是同步展开请求：合集会逐个查询视频分P，前端必须为 `expandUrl` 传入独立的长超时（当前为 `120s`），不受普通 API 的 `30s` Axios 默认超时影响。

## 验收

- 合集/多P/单P 三种 URL 均能正确展示；
- 全选、全不选、`x-x` 解析正确（含边界，如 `3-3`、越界）；
- 已生成条目默认不勾选且置灰；
- 弹窗关闭不产生副作用。
