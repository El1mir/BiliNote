## 1. 目标

### A. 视频理解采样方式
在现有「间隔采样」之外，新增**高价值帧采样**与**综合采样**，通过下拉列表选择采样方式：

- **间隔采样**：现状，按固定秒数抽帧；
- **高价值帧采样**：算法挑出信息量大的帧：
  1. **画面变化采样**：镜头切换/画面变化剧烈处采样；
  2. **字幕分割采样**：转写字幕分段边界处采样；
  3. 合并去重 → 按时间排序 → 按**限制方式二选一**截断（见下）；
     — ⚠️ 2026-09-26：`total` 模式下候选不足时**补均匀采样**，避免画面变化少的课只抽到几张（ticket 09）；
  4. 仍走现有**拼图**（`grid_size`）后交给多模态模型理解。

> ⚠️ 2026-09-26 修订（见 ticket 08）：限制方式**二选一**，只生效一个：
> - `frame_limit_mode="total"`（默认）：只用 `max_frames`，收全部候选后均匀降采样；
> - `frame_limit_mode="per_second"`：只用 `frames_per_second`，每秒最多 N 帧，不做全片总量截断。
>
> 批量模式下两者都按**每个视频各自**计算（不共享/摊薄）。

- **综合采样**（`sampling_mode="hybrid"`，见 ticket 10）：三路来源**全都用**——
  高价值帧（场景+字幕）+ 均匀采样 + **LLM 按字幕选帧**（输出 JSON 时间点）；
  配额约 40%（LLM）/ 30%（高价值）/ 剩余（均匀），某路不够时让给均匀采样。
  LLM 用当前笔记模型，失败自动降级为「高价值+均匀」，不影响任务。

### B. 批量模式融入表单
把批量能力从「独立按钮」改为表单里的一个**模式选项**：

- 勾选「批量模式」后：
  - 表单标签为「批量模式」；
  - **来源下拉只保留 bilibili 选项**（不禁用，切过去自动选中）并强制 `bilibili`；
  - 链接只填在**主表单**输入框（合集链接或多P视频链接），对话框内不再重复输入；
  - 主按钮由「生成笔记」变为「**展开预览**」；
- 点「展开预览」→ **先在主表单请求 `/api/expand`**，成功后才打开对话框
  （复用/改造 spec 001 的 `BatchImportDialog`，见 ticket 07）：
  - 展开出合集内视频 / 多P 分P；
  - 勾选需要的 P 或视频（全选 / 全不选 / `x-x` 范围）；
  - 对话框内「**确定生成**」或「**取消**」。

## 2. 非目标

- 不改动单视频（非批量）模式的常规生成流程，仅新增采样方式选项。
- 不引入新的多模态模型/供应商抽象。
- 不做「合集自动全量生成」——仍由用户在对话框勾选确认。

## 4. 接口/配置草案

### 4.1 生成请求新增字段
`VideoRequest` / `BatchGenerateRequest` 增加：

```json
{
  "sampling_mode": "interval | smart",
  "frame_limit_mode": "total | per_second",
  "max_frames": 60,
  "frames_per_second": 2
}
```

- `interval`：沿用 `video_interval`（秒）。
- `smart`：忽略 `video_interval`，用算法选帧；限制方式**二选一**：
  - `frame_limit_mode="total"`（默认）：只用 `max_frames`（该视频总量上限，默认 60）；
  - `frame_limit_mode="per_second"`：只用 `frames_per_second`（每秒上限，默认 2）；
  - 未选中的那个参数**不生效**；批量时按**每个视频各自**计算。

### 4.2 表单新增
- `batch_mode: boolean`
- `sampling_mode: 'interval' | 'smart' | 'hybrid'`
- `frame_limit_mode: 'total' | 'per_second'`（仅 `smart` 显示，限制方式二选一）
- `max_frames: number`（`total` 模式显示，单个视频上限，默认 60）
- `frames_per_second: number`（`per_second` 模式显示，默认 2）
