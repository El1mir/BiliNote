# 004 · 笔记里的 LaTeX 公式渲染

- **状态**：implemented
- **日期**：2026-09-26
- **范围**：前端 Markdown 渲染（笔记预览 + AI 问答面板）
- **上游**：无（独立于 001/002/003）

---

## 1. 背景与现象

生成的笔记（尤其数学讲解类）里，公式没有渲染成数学，而是以纯文本露出：

```
函数 ( f(x) = \frac{\ln x}{x} )：
求导：( f'(x) = \frac{1 - \ln x}{x^2} )。
```

注意 `\(` 变成了 `(` —— 说明它被 Markdown 当成了**转义括号**，公式没被识别。

## 2. 根因

模型输出的是 **LaTeX 原生分隔符** `\( ... \)` / `\[ ... \]`；
而前端渲染链是 `react-markdown` + `remark-math` + `rehype-katex`，
**`remark-math` 只认 `$...$` / `$$...$$`**。

所以 `\(` 落入普通文本，`\` 触发 Markdown 转义，括号被保留、反斜杠消失。

## 3. 方案

在交给 `ReactMarkdown` 之前做一次**分隔符归一化**：

| 原样 | 归一化后 |
|---|---|
| `\( ... \)` | `$ ... $` |
| `\[ ... \]` | `$$ ... $$` |

- 已经是 `$` 形式的公式不动；
- **跳过 ``` 围栏代码块**，避免破坏代码示例里的 `\(`；
- 纯函数放在 `src/utils/markdown.ts`，便于单测。

> 不选「改提示词让模型输出 `$`」：模型不保证遵守，而且**存量笔记**也得能正常显示。
