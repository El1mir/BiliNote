# 01 · 后端任务阶段模型与兼容状态文件

- **依赖**：无
- **关联**：spec §4、§5
- **状态**：已完成

## 目标

建立标准阶段、阶段标签、阶段权重和状态文件扩展能力，保留原有 `status` 读取方式。

## 改动点

1. 扩展任务阶段定义和中英文/中文展示标签。
2. 增加阶段权重及全局进度计算工具。
3. 扩展 `_update_status`，写入 `stage`、`stage_label`、`progress`、`stage_progress`、`message`、`detail`、`updated_at`。
4. 兼容旧调用：只传 `TaskStatus` 时仍能生成合法旧格式状态。
5. 为状态文件写入增加统一类型和边界校验。

## 验收

- 旧状态文件可读取。
- 新状态文件同时包含旧 `status` 和新阶段字段。
- 没有可靠进度时字段为 `null`，不生成伪造百分比。
- 阶段切换和失败信息有单元测试。
