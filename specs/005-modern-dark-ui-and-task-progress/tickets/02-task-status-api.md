# 02 · 任务状态接口扩展与阶段权重

- **依赖**：01
- **关联**：spec §5
- **状态**：已完成

## 目标

让 `/api/task_status/{task_id}` 原样返回新阶段协议，并保持成功、失败、缺失文件等旧行为兼容。

## 改动点

1. 处理中状态返回完整阶段字段。
2. 成功响应保留 `result`，同时返回最终阶段信息。
3. 失败响应保留现有错误结构，并暴露最后阶段、消息和详情。
4. 无状态文件时继续返回 `PENDING`，新字段使用兼容默认值。
5. 增加接口测试覆盖旧客户端字段和新客户端字段。

## 验收

- 旧前端只读取 `status` 时测试通过。
- 新前端可只依赖统一阶段字段渲染任务详情。
- 任务状态接口不会因为新增字段破坏成功/失败分支。
