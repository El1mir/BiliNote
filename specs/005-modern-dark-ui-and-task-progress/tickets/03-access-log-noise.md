# 03 · Uvicorn 状态轮询日志过滤

- **依赖**：无
- **关联**：spec §6
- **状态**：已完成

## 目标

停止成功的任务状态轮询刷屏，同时保留异常请求和其他 API 的访问日志。

## 改动点

1. 为 Uvicorn access logger 增加只匹配 `/api/task_status/` 的过滤器。
2. 仅过滤 2xx 成功响应；4xx/5xx 不过滤。
3. 不影响应用 logger 中的阶段切换、失败和完成日志。
4. 为过滤器增加纯单元测试，覆盖 query string、尾部斜杠和非轮询路径。

## 验收

- 长任务期间控制台不再出现连续的 `GET /api/task_status/... 200 OK`。
- 状态接口异常时仍能从日志看到请求。
- 其他 GET/POST API 的访问日志保持现状。
