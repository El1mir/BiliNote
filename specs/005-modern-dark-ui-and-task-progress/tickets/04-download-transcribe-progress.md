# 04 · 下载、字幕、转写流程进度埋点

- **依赖**：01、02
- **关联**：spec §5
- **状态**：已完成

## 目标

把解析、字幕获取、视频下载、音频下载和转写拆成前端可观察的后端阶段。

## 改动点

1. `parsing` 阶段记录任务初始化和输入解析。
2. 增加 `fetching_subtitles`，区分缓存、平台字幕成功和转写回退。
3. 将视频与音频下载拆成 `downloading_video`、`downloading_audio`。
4. 下载器支持回调时透传字节/片段进度；不支持时显示活动状态。
5. 转写支持切片总数、当前切片和已完成数量详情。
6. 缓存命中时写入明确消息和可完成的阶段进度。

## 验收

- 有字幕和无字幕两条路径都能显示正确阶段。
- OpenAI ASR 分片、静音切片和本地转写不会丢失阶段更新。
- 下载器不提供分母时不显示虚假百分比。
