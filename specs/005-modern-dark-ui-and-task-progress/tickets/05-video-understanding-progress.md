# 05 · 采样、抽帧、拼图流程进度埋点

- **依赖**：01、02
- **关联**：spec §5；002
- **状态**：已完成

## 目标

让视频理解长流程从一个隐藏步骤变成规划采样、抽取画面、拼接网格图三个可观察阶段。

## 改动点

1. smart/hybrid 采样进入 `planning_frames`，记录候选来源和数量。
2. LLM 选帧记录开始、成功、降级和失败原因，但失败仍遵循现有降级策略。
3. `VideoReader.extract_frames` 支持当前帧/总帧数详情。
4. `concat_images` 支持当前网格/总网格详情，并保留最后不完整网格。
5. interval、smart、hybrid 三种模式都能产生合法阶段序列。

## 验收

- 140 帧、16 个网格的任务可以显示抽帧和拼图进度。
- 最后一组不足一格时进度仍能完成，不出现卡住或倒退。
- LLM 选帧不可用时阶段详情明确显示降级，而不是任务失败。
