# 07 · 前端任务类型、轮询和持久化适配

- **依赖**：02
- **关联**：spec §5；001
- **状态**：待实现

## 目标

让前端任务模型完整保存后端阶段字段，并兼容已有 local/persist 任务数据。

## 改动点

1. 扩展 Task 类型：stage、stageLabel、progress、stageProgress、message、detail、updatedAt。
2. 轮询成功时合并全部阶段字段，而不只更新旧 status。
3. 保留连续轮询失败保护，避免网络抖动误判任务失败。
4. 旧任务缺少新字段时使用兼容默认值。
5. 清理终态任务的轮询计数和临时状态。

## 验收

- 刷新页面后任务阶段、详情和进度仍能恢复。
- 状态字段为未知值时 UI 不崩溃，有通用回退展示。
- 多任务轮询互不覆盖阶段信息。
