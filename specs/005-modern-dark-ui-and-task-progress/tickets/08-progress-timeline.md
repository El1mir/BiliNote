# 08 · 前端完整阶段时间线与进度组件

- **依赖**：07
- **关联**：spec §7
- **状态**：待实现

## 目标

用与后端阶段协议一致的时间线替代当前单薄的固定 StepBar。

## 改动点

1. 新增阶段时间线组件，显示已完成、当前、待处理、失败四类状态。
2. 同时展示全局进度和当前阶段进度；进度为 null 时显示活动指示器。
3. 展示当前阶段 message/detail、切片数、帧数、网格数等上下文。
4. 支持窄屏滚动和长阶段详情截断/展开。
5. 使用 lucide 图标和现有 shadcn 风格组件，避免依赖大段说明文字。

## 验收

- 阶段顺序和后端协议一一对应。
- 不会把未知阶段错误标记为已完成。
- 任务失败时保留失败阶段和错误消息。
- 桌面和窄屏无重叠、溢出或布局跳动。
