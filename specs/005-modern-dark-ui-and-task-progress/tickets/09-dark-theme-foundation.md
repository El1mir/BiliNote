# 09 · 暗色设计 token 与基础组件统一

- **依赖**：无
- **关联**：spec §4、§7
- **状态**：待实现

## 目标

建立全站暗色紫红设计基础，统一颜色、边框、控件、反馈状态和图标使用。

## 改动点

1. 在 Tailwind/CSS 变量中定义背景、表面、边框、文字、主色、悬停色和状态色 token。
2. 以 `#1A1A1A`、`#2B2B2B`、`#4A4A4A`、`#6B6B6B` 和紫红色阶为基础，补充必要的透明度和对比度阶。
3. 统一 Button、Card、Input、Select、Dialog、Tabs、Badge、Toast、Tooltip 样式。
4. 统一 lucide 图标尺寸、按钮语义、焦点环和禁用态。
5. 清理亮色页面级背景和旧主题冲突样式。

## 验收

- 核心页面无明显亮色旧组件混杂。
- 正文、控件和状态色满足可读性与键盘焦点要求。
- 不改变现有组件的功能和表单提交行为。
