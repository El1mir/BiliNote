# 11 · 笔记查看与设置页重构

- **依赖**：09
- **关联**：spec §7
- **状态**：待实现

## 目标

统一笔记阅读、转写、对话、Markmap 和设置页的暗色体验，同时保留所有现有能力。

## 改动点

1. 重构 MarkdownViewer、ChatPanel、转写查看和相关工具栏。
2. 保留 LaTeX、代码块、截图、视频链接和 Markdown 版本能力。
3. 统一设置页导航和 Model、Downloader、Transcriber、Prompt、Monitor、About 页面布局。
4. 保留端点增删、模型配置、下载配置、Prompt 编辑和监控功能。
5. 用 lucide 图标补齐复制、下载、重试、关闭、展开等操作的可发现性。

## 验收

- 笔记内容、公式、截图、对话和转写数据均能正常查看。
- 设置数据可读取、编辑、保存和删除。
- 页面在窄屏下不出现表单字段、按钮或正文溢出。
