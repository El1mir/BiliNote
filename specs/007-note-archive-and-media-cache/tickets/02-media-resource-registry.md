# 02 · 媒体资源登记、迁移与旧文件回填

- **关联**：spec §4 决策 4–7；§5

## 目标

建立资源级生命周期记录，让新产生的截图、视频、音频有固定的产生时间、文件信息和到期时间，并安全兼容已有安装目录。

## 改动点

1. 新增资源 SQLAlchemy 模型/DAO 与初始化兼容；明确 SQLite 已有数据库采用幂等 schema 迁移，不依赖 `create_all()` 给既有表加列。
2. 登记资源类型、task/video 关联、相对受管路径、大小、产生时间、到期时间、回填来源和清理状态。
3. 文件产出/下载成功后登记；登记失败时不得静默丢失可清理性，记录错误并提供可重试补登记路径。
4. 首次启用扫描截图目录和 DATA_DIR 中允许的音视频文件，按 mtime 和默认值（截图 7 天、音视频 3 天）回填；回填幂等且不覆盖既有记录。
5. `0` 保留期存为无到期时间；配置值变更不重算任何已登记记录。
6. 仅接受配置根目录内的规范化相对路径；清理 DAO/服务不暴露任意绝对路径。

## 验收

- 空库、现存旧库、重复启动和部分回填失败均可恢复。
- 回填的到期时间为 mtime + 默认类别天数；已经过期的资源可立即进入清理流程。
- 资源登记与文件产出失败场景有测试覆盖。


## 实现说明

- 资源模型、SQLite 增量迁移和启动回填已实现；自动化覆盖尚未执行。
