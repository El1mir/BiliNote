# 03 · 保留期设置、自动清理与手动清理

- **依赖**：02
- **关联**：spec §4 决策 4–8；§5、§8
- **状态**：实现已落地；后台清理生命周期与验收测试待用户授权

## 目标

提供可理解、可预览、可恢复错误的缓存清理能力；自动清理只处理已到期记录，手动清理可按类别主动回收。

## 改动点

1. 持久化截图保留期默认 7 天、视频/音频默认 3 天；允许非负整数，0 表示禁用该类自动过期。
2. 增加后台周期清理器，采用有界批次；不得阻塞启动或任务主线程，删除失败可重试。
3. 提供资源统计和清理预览：类别、数量、总字节、到期范围；提供“清理到期资源”和按类别强制清理。
4. 设置 UI 支持修改保留天数、查看最近清理结果和手动清理；强制清理必须展示将删除的类别/数量/空间并二次确认。
5. 清理文件时仅解析资源表中的受管路径；缺失文件清理陈旧记录，删除失败保留失败状态和错误信息。
6. 记录清理审计日志，含类别、数量、字节和结果，不记录敏感完整路径。

## 验收

- 新设置仅影响之后生成的资源；已有 expires_at 不变。
- 自动任务只删 expires_at <= 当前时间的资源；0 类别不会被自动删除。
- 手动预览和执行范围一致；路径越界记录被拒绝；部分失败可重试。

- 清理竞态、失败重试、路径防护及真实 SQLite 生命周期待后端测试验收。
